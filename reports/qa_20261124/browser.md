# 独立浏览器测试与缺陷复测

执行日期：2026-11-24；平台 macOS 26.6.2；Google Chrome 158.0.8127.88；Playwright 1.56.1。最终应用依赖 Vite 6.4.5、FastAPI 0.165.0、Starlette 1.10.0。浏览器为真实 headless Chrome，服务是本机 8003 端口，数据库每次使用独立临时文件，`DATA_ORIGIN=test`。不连接用户演示数据库。

## 方法

从任务书导出异常路径，用真实浏览器覆盖正常操作、故障注入、时序竞态、边界宽度、键盘操作和展示正确性。测试未读入 60 条合成任务标签。先保存失败证据，再修改实现，保留可重复回归用例。禁用自动重试（retries=0），避免掩盖偶发失败。

- 业务结果使用真实 API/数据库状态校验，不以 HTTP200 或按钮点击成功代替。
- 网络故障模拟服务端已建单但响应丢失，再点击同一确认按钮，核对只有一个工单。
- 竞态测试截留旧身份已授权的 HTTP 响应，切换身份后才释放，检验旧数据是否再次显示。
- 键盘测试使用逐字符输入与实际 Tab/Shift+Tab/Escape，避免 `fill()` 掩盖焦点丢失。
- 抽样对比度读取浏览器计算后的前景/背景色，采用相对亮度公式计算。普通文本门槛参考 [W3C WCAG2.2 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)；焦点行为参考 [W3C 模态对话框模式](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。这是定向检查，不是完整无障碍认证。

## 已复现且修复的7个独立缺陷

|编号/严重度|复现与实际表现|修复及回归|
|---|---|---|
|UI-D01 P1|延迟HR01已授权列表/详情，切换HR02或emp02后释放。前者可显示广州组记录，后者弹出旧HR工单详情。属于浏览器旧响应暴露，并非证明新身份绕过服务器ACL|API响应绑定身份世代，切换后丢弃旧响应；工作区组件按用户重建。QA-UI-04/05|
|UI-D02 P1|知识草稿标题逐键输入“Policy editor keyboard”，只留下首字母P，其余键击未进入输入框|模态生命周期不再依赖每次重建的关闭回调，改稳定ref。QA-UI-11|
|UI-D03 P2|打开新建请求即按Shift+Tab，焦点进入背景页面|初始焦点移入可用控件，正反方向循环，关闭还原，嵌套仅顶层处理。QA-UI-02|
|UI-D04 P2|已有指标后把开始日设为无效范围，后端拒绝但旧数字仍呈现，容易被当作新范围结果|切换筛选清空旧数据、取消旧查询结果、明确失败状态。QA-UI-06|
|UI-D05 P2|普通说明与材料状态文字抽样对比度约2.41–3.07:1，低于4.5:1目标|加深次级文字和各状态标签，保留状态文案与颜色。原始contrast-initial.json、复测contrast.json，QA-UI-07|
|UI-D06 P2|工单被另一请求更新后显示版本冲突，但详情没有刷新入口；关闭重开会丢失草拟回复|增加保留输入的“刷新请求”动作，QA-UI-10|
|UI-D07 P2|界面按上海日历筛选，却发送裸日期，后端按UTC零点解析；统计边界相差8小时，结束日含义不明|发送YYYY-MM-DDT00:00:00+08:00，标明结束日不含；CSV使用同一查询，QA-UI-14；后端另有时间边界夹具|

P1表示影响核心操作或角色数据隔离的高优先级问题；P2表示正常功能受限、错误呈现或可访问性问题。只报告真实复现的项目。多个测试触发同一根因时只计一个缺陷。

## 失败证据与透明说明

- `browser-initial.json`：最初10条执行4通过/6失败，其中HR列表一次夹具未等待新响应、详情一次选择了新建ID而非拦截的种子ID。没有把这两个夹具问题直接计为应用缺陷。
- `browser-reproduction-initial.json`：修正拦截夹具后，HR列表跨身份显示、HR详情跨身份弹出、知识逐键输入三项均明确复现。
- `browser-date-initial.json`：日期请求原值为裸日期，明确复现时区错误。
- `browser-6.4.4.json`：中间补丁版本的16项通过结果；依赖复查后进一步升级到6.4.5。
- `browser-results.json`：最后版本的完整结果；公开成功截图位于screenshots。测试时留存的失败trace及artifact目录仅本机保存，不随公开仓库发布；初次失败JSON保留附件记录与错误结果，公开范围见[证据说明](../PUBLICATION.md)。

## 执行命令

从frontend目录运行：

```sh
npm run build
npm exec -- playwright test --config playwright.qa.config.ts
```

配置自动启动隔离后端，不复用8000演示进程，旧报告路径不覆写。原有workflow测试支持QA_SCREENSHOT_DIR，让QA截图写入本轮目录。npm包版本固定在package.json和package-lock.json。

## 未覆盖与限制

没有执行Safari、Firefox、Windows、Linux、屏幕阅读器和真实触屏设备测试；320/390为Chrome视口模拟。未使用axe进行全站规则扫描，没有宣称WCAG全项达标；对比度仅覆盖所列可见文字样本，复杂透明叠加/图片文字未全面扫描。无真实企业数据、外部HRIS或真实模型测试。上述17项是测试用例数量，不是独立用户样本或业务收益，也不证明不存在其他缺陷。
