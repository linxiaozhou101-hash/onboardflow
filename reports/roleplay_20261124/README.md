## 仍需改进的角色体验

1. **IT找任务仍费力**：种子旧任务与本次待办混排，卡片没有可见工单/任务编号，未提供待办筛选。脚本按测试属性定位只证明状态正确，不能证明人工查找容易。具体任务说明已改善本次区分，但不能代替队列整理。
2. **前置协作信息不够直观**：系统能拦截依赖未完成，但IT页面未清楚展示前置经办人的联系线索。当前仍由HR协调。
3. **档案纠错没有页面闭环**：员工可补原本为空的自报条件；已有档案信息错误时，HR页面缺修改入口。后端接口已有，并不等于HR已能在页面完成该工作，本轮不以API写入绕过。
4. **自报与档案显示容易混淆**：自报深圳及日期已参与匹配，但顶部原档案仍显示“待完善”；来源解释可更直观。
5. **统计明细偏技术格式**：管理员可以追溯和复算，但draft_id、invalid、ease等字段不便一线快速理解。
6. **重开表单残留旧输入**：再次确认后仍显示上一次的重开原因，可能造成重复点击；此项为非阻塞界面问题，尚未修复。
7. **交接需主动刷新**：页面提供刷新按钮，无实时推送、真实消息发送或真实IT开通。实际材料真实性和实际账号可用性未验证。

下一步真人探索性测试宜优先观察：员工能否解释“申请获批但材料未齐”；IT能否在多个同人同类型卡片中找到正确待办；HR能否处理档案错误；管理员能否不借助技术人员理解分母与低分明细。真实访谈、任务耗时、语义人工复核和远程模型测试仍未执行。
