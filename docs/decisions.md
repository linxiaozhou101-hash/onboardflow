# 环境检查与普通技术决策

2026-11-24 完整读取 `HR数字化_Codex执行方案.txt`。初始仓库为空，无 README、依赖、运行脚本或 AGENTS.md，Git 未有提交；未覆盖已有业务。检查了当前目录和父级约束文件。

本机 Python 3.14.2、Node 24.13.0、npm 11.6.2；8000、5173 最初空闲。受限环境首次 pip 无法解析外网域名，经工具授权联网后安装成功。依赖锁定见 backend/requirements.lock 与 frontend/package-lock.json。核对了 [FastAPI TestClient](https://fastapi.tiangolo.com/tutorial/testing/)、[FastAPI 数据库教程](https://fastapi.tiangolo.com/tutorial/sql-databases/) 和 [Vite 官方指南](https://vite.dev/guide/)；使用实际安装与测试确认兼容性。

1. 使用 FastAPI/Pydantic 和标准库 SQLite，不增加可选 ORM。业务动作集中在 cases.py，查询、授权、检索、指标各有独立模块，显式事务使回滚边界易于验证。
2. 表结构使用 PRAGMA user_version=1 进行首版幂等初始化；未实现未来跨版本自动数据迁移，未来 schema 变更需显式 migration。
3. 中文检索自行实现字符 1–3 gram TF-IDF 与余弦，无需额外科学计算依赖；不是按空格切分。规则由知识模块 RULES 定义，并生成可读段落。
4. React/TypeScript/Vite，轻量 CSS、Lucide 图标，指标采用原生条形图。通过后端代理保持同源，提交使用 CSRF token 与来源校验。
5. 时钟通过 db._clock 可替换；内部 UTC，前端 Asia/Shanghai。种子固定 2026-11-24 基准，运行时不固定“今天”。
6. 数据来源拆分 demo/manual/test，种子只初始化一次。72 个历史请求按合法流转逐步写事件，不仅填最终状态。固定构造无随机抽样，重复初始化不改变结论。
7. 远程适配器不取代规则答案，只提供经 schema 与引用白名单验证的归纳草稿；8 秒超时，零自动重试，缺 Key 继续离线。没有真实远程模型测试或收益推断。
8. 材料审批和材料实际提供是独立状态。延期处理完毕后保留 provided=false 和可继续的非必需跟进；取消在同事务终止未完成子任务。
9. 本地演示以固定账号切换，不做密码/SSO。生产部署需要另外设计，不在本次 MVP 范围。

安装补充：npm 官方仓库在本环境连接超时，改用公开 npmmirror 镜像并使用独立临时缓存，绕开用户缓存目录写入失败；版本与完整性校验写入 package-lock.json。未修改用户全局 npm 配置。
