# 作品说明：入职服务工作台

围绕入职服务中的重复咨询、材料补问与跨部门进度不透明，构建适用制度检索、请求办理、任务协同和服务分析的本地原型。需求边界、流程与评价依据用户任务书；实现由 Codex 辅助完成。入职服务场景、员工、制度、SLA 和历史请求全部为模拟，未接入真实企业系统。

## 可展示的工作

从三个任务出发建立角色权限与状态机；将“已回复”“申请已处理”“材料已收齐”“员工确认”拆开；用结构化规则处理政策范围、日期和版本；把缺项失败尝试写入数据库，使首次完整率能够复算；为员工、HR 和 IT 提供各自可见的操作界面。

检索与离线模板负责整理有权限的依据，审批、状态、分派及完成条件由后端决定。可选模型输出必须通过结构与引用检查，不可直接调用业务写入。无密钥仍可完成流程。

## 证据与尚待验证

实际自动测试、合成任务结果和失败案例在 `reports/`。自动字符串/规则检查只能筛查事实与动作，不构成完整语义评价；人工判定表待填写。真实模型调用、真实用户测试及跨平台验证是否执行，以交付报告为准，不从离线成绩推断。

## 下一轮

优先邀请 5–8 位参与者，覆盖 HR 与近期入职员工，检验对审批/材料/确认状态的理解；记录错误、补问、正确完成率和失败原因。若发现制度范围或完成条件难理解，先改善规则文案与流程，再讨论远程模型是否增加价值。

限制：本地固定演示身份不是企业认证；SQLite 单实例，无工作日 SLA；只检查元信息；不同政策之间任意语义冲突不能全面识别；未对真实企业政策、法律结论或真实账号开通作保证。
